# Redstone Essentials (`redstone_essentials`)

A Fabric mod introducing essential redstone components and utilities for Minecraft.

## Requirements

* **Minecraft:** `26.3`
* **Fabric Loader:** `>=0.19.5`
* **Fabric API**
